# Executive & Commerce Notes Hub

منصة تعليمية عربية/إنجليزية لتنظيم مواد السكرتاريا التنفيذية وإدارة المكاتب. تعمل كواجهة ثابتة (Static Website) ويمكن نشرها مجاناً باستخدام **GitHub Pages**.

## ما الذي يتضمنه المشروع؟

- تصميم متجاوب باللونين الأبيض والأزرق للهواتف والحواسيب.
- خمسة فصول دراسية مع عناوينها وملخصاتها التمهيدية بالإنجليزية والعربية.
- الموضوعات المستخرجة من ملفات المقررات الخمسة.
- النص المستخرج من كل PDF للبحث والقراءة، مع إبقاء ملف PDF الأصلي مرجعاً أساسياً.
- مكتبة لتحميل ملفات PDF الأصلية.
- بحث عام في أسماء الفصول والموضوعات والملخصات والنصوص المستخرجة.
- قاموس مصطلحات إنجليزي/عربي قابل للبحث.
- اختبارات تدريبية قصيرة مع تصحيح فوري وتفسير الإجابة.
- حفظ تقدم القراءة ونتائج الاختبارات محلياً في المتصفح باستخدام LocalStorage.
- خريطة موقع أولية وملف robots.txt، وسير عمل للنشر التلقائي عبر GitHub Actions.

## نشر الموقع على GitHub Pages — خطوة بخطوة

1. سجّل الدخول إلى GitHub وأنشئ مستودعاً جديداً (New repository).
2. سمِّ المستودع مثلاً: `executive-commerce-notes-hub`.
3. اجعل المستودع **Public** إذا أردت رابطاً عاماً مجانياً.
4. فك ضغط ملف ZIP الذي نزّلته.
5. افتح المستودع في GitHub، ثم اختر **Add file → Upload files**.
6. ارفع **كل محتويات المجلد** إلى جذر المستودع، وليس مجلد ZIP نفسه. تأكد أن `index.html` ظاهر مباشرة في الصفحة الرئيسية للمستودع.
7. اضغط **Commit changes**.
8. افتح **Settings → Pages**.
9. ضمن **Build and deployment** اختر **Source: GitHub Actions**.
10. افتح تبويب **Actions** وانتظر اكتمال مهمة `Deploy static site to GitHub Pages` بنجاح.
11. سيظهر رابط موقعك في **Settings → Pages**، وغالباً يكون بالشكل:
    `https://USERNAME.github.io/REPOSITORY/`

بعد ذلك، كل مرة ترفع فيها تعديلاً إلى فرع `main` سيُعاد نشر الموقع تلقائياً.

**خطوة أخيرة لمحركات البحث:** افتح `sitemap.xml` و`robots.txt` واستبدل `USERNAME` و`REPOSITORY` باسم حسابك واسم المستودع الفعليين. هذه الخطوة اختيارية لعمل الموقع نفسه، لكنها مفيدة للفهرسة.

## تحديث المحتوى

- بيانات الفصول والموضوعات والنصوص: `data/chapters.json`.
- ملفات PDF والنصوص الأصلية: `materials/`.
- تصميم الموقع: `assets/style.css`.
- وظائف الموقع والبحث والاختبارات: `assets/app.js`.
- الصفحة الرئيسية وبنية الواجهات: `index.html`.

## مهم — حدود النسخة الحالية

هذه نسخة مكتملة كمنصة **ثابتة قابلة للنشر على GitHub Pages**، وليست نظاماً خلفياً متكاملاً:

- لا يوجد تسجيل حسابات حقيقي أو كلمات مرور أو صلاحيات مستخدمين. لا تدخل كلمة مرور حقيقية في موقع ثابت.
- التقدم والنتائج محفوظة على المتصفح والجهاز نفسه؛ لا توجد مزامنة بين الأجهزة ولا قاعدة بيانات سحابية.
- لا توجد لوحة تحكم لإدارة المستخدمين أو المحتوى.
- لا يوجد مدرس ذكاء اصطناعي مدمج.
- الملخصات الحالية تمهيدية، والاختبارات أسئلة تدريبية أولية وليست بنك امتحانات شاملاً أو ترجمة كاملة لكل صفحات الكتب.
- قد لا يحافظ النص المستخرج آلياً على تنسيق الجداول والصور؛ ارجع إلى PDF الأصلي عند الحاجة.
- GitHub Pages لا يشغّل خادماً خلفياً أو قاعدة بيانات. لإضافة حسابات حقيقية ومزامنة ولوحة إدارة، ستحتاج خدمة خلفية منفصلة وقواعد أمان وخصوصية.
