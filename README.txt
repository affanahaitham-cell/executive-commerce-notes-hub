Executive & Commerce Notes Hub

هذه النسخة مجهزة للنشر على GitHub Pages.

خطوات النشر:
1) أنشئ مستودعاً جديداً على GitHub، ويفضل أن يكون Public.
2) فك ضغط الحزمة.
3) ارفع كل محتويات المجلد إلى جذر المستودع؛ يجب أن يكون index.html في الجذر مباشرة.
4) اضغط Commit changes.
5) افتح Settings ثم Pages.
6) اختر Source: GitHub Actions.
7) من تبويب Actions انتظر اكتمال Deploy static site to GitHub Pages.
8) خذ رابط الموقع من Settings > Pages.

كل تحديث ترفعه إلى main سيُنشر تلقائياً.

تتضمن المنصة 5 ملفات PDF أصلية، نصوصها المستخرجة، عناوين الفصول، ملخصات تمهيدية ثنائية اللغة، قاموساً، اختبارات تدريبية، بحثاً عاماً، وحفظاً محلياً للتقدم.

تنبيه: GitHub Pages يستضيف مواقع ثابتة فقط. تسجيل الدخول الحقيقي، قاعدة البيانات السحابية، مزامنة المستخدمين، لوحة الإدارة، ومدرس الذكاء الاصطناعي تحتاج خدمات خلفية منفصلة. لا تدخل كلمات مرور حقيقية في هذه النسخة. الملخصات والأسئلة حالياً تمهيدية وليست ترجمة كاملة أو بنكاً شاملاً.
راجع README.md للتفاصيل.
